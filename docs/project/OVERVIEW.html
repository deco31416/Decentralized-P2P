CambiaCripto

Un proyecto en desarrollo para explorar cómo una interfaz web y contratos inteligentes podrían apoyar experiencias de intercambio entre pares de activos digitales y fiat.

Estado y límites. Esta página describe la intención del proyecto, no un servicio financiero disponible. La presencia de interfaces o contratos fuente no acredita que los flujos funcionen, que exista un despliegue activo, que el sistema esté auditado o que sea seguro para fondos reales.

Qué hay en el repositorio

Una aplicación web con Next.js, React y TypeScript; utilidades de integración Web3; y fuentes Solidity organizadas por módulos con configuración de Hardhat.

Qué explora

Rutas de interfaz para dashboard, depósitos, retiros, staking, IDO y distintas vistas P2P, junto a contratos organizados para exchange, escrow, gestión y funciones adicionales.

Qué no se afirma

No se afirma soporte multi-chain operativo, liquidación fiat en cadena, custodia segura, auditoría independiente, volumen, usuarios, contratos desplegados ni disponibilidad de producción.
